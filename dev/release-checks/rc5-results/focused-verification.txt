   source_url with unescaped slashes, "Success: Done.") and of an error (exit 1, error code). Fails on
   RC4: "Failed asserting that an array contains 'status: "updated"'". Test helper: start_cli() adds
   --format=json only when no format is given.
ConcurrencyTest::test_lock_check_in_a_transaction_blocks_a_takeover_until_the_commit: inside a
   transaction, is_held( true ) locks the lock row; a second connection's takeover UPDATE fails with
   "Lock wait timeout" (innodb_lock_wait_timeout 1) and succeeds after the COMMIT. Passes on RC4 and RC5
   lock code (behavior preserved).
